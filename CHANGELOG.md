# Изменения

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [1.0.0] — 2026-06-06

Первый production-релиз. Прогрессивное веб-приложение (PWA) для составления
ежемесячных отчётов Добровольной Народной Дружины — наследник консольной
утилиты на matplotlib.

### Добавлено
- Генерация A4-PDF целиком в браузере (pdf-lib + fontkit), офлайн, кириллица
  через встроенные шрифты.
- Два стиля бланка: **Классический** (точная копия исходного matplotlib-отчёта,
  DejaVu Sans) и **Модерн** (свежая вёрстка: таймлайн, строка-сводка,
  колонтитул с подписью и номером страницы; шрифты PT Serif + PT Sans).
- Живой WYSIWYG-превью страницы с пагинацией; общий движок вёрстки для PDF и
  превью гарантирует совпадение.
- Редактор мероприятий: пункты и подпункты, перемещение, авто-рост полей,
  удаление любого элемента, кнопка «Сбросить».
- Заполнение по образцу прошлого месяца (кнопка и точечные подсказки).
- Профили отрядов: создание, переключение, дублирование, удаление,
  экспорт/импорт профиля файлом.
- Окружение отряда: данные, эмблема (с авто-обрезкой прозрачных полей),
  цвета бланка, тексты-шаблоны, почта.
- История отчётов по отряду (IndexedDB) + импорт архива старого проекта.
- Отправка отчёта: в один клик через сервер-релей (SMTP, без зависимостей),
  иначе — системное «Поделиться» или почтовый клиент.
- PWA: установка как приложение, офлайн через service worker, тёмная/светлая тема.
- Импорт/экспорт месячного JSON, совместимого со старым проектом.

### Инфраструктура
- Автотесты (node:test): движок PDF, пагинация, GUI-смоук в jsdom.
- CI на GitHub Actions, автодеплой на GitHub Pages.
