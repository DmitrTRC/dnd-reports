# Участие в разработке

Спасибо за интерес к проекту! Ниже — как запустить и проверить код.

## Требования

- Node.js 18+ (для тестов)
- Python 3 (для локального сервера и сервера отправки)

## Локальный запуск

```bash
git clone https://github.com/DmitrTRC/dnd-reports.git
cd dnd-reports
npm install            # только dev-зависимости для тестов
npm run serve          # открыть приложение на http://localhost:8000
```

Само приложение — статика в `dnd-report-pwa/` и работает без сборки.
Внешних рантайм-зависимостей нет: pdf-lib, fontkit и шрифты лежат в репозитории.

## Тесты

```bash
npm test
```

Покрытие:
- `tests/pdf.test.js` — генерация PDF (классический и «Модерн»), пагинация
  вёрстки, перенос строк и нумерация.
- `tests/gui.test.js` — смоук-тест интерфейса в jsdom: загрузка, сид архива,
  дефолты почты, выбор стиля, заполнение по образцу, рендер превью.

CI прогоняет `npm test` на каждый push и pull request.

## Структура

```
dnd-report-pwa/        приложение (PWA)
  js/                  логика: report-pdf, layout-modern, preview, store, app
  vendor/ fonts/       офлайн-библиотеки и шрифты
  server/              сервер отправки писем (Python stdlib)
  samples/             архив отчётов
tests/                 автотесты (node:test)
.github/workflows/     CI и деплой на Pages
```

## Стиль кода

- Vanilla JS (ES2018+), без сборщика и фреймворков.
- Один источник правды для вёрстки: `layout-modern.js` отдаёт op-список,
  который рисуют и PDF-движок, и превью — правьте логику там, а не дублируйте.
- Комментарии и тексты интерфейса — на русском.

## Pull request

1. Создайте ветку от `main`.
2. Убедитесь, что `npm test` проходит.
3. Опишите изменения; при заметных правках обновите `CHANGELOG.md`.
