# Отчёты ДНД — PWA

Прогрессивное веб-приложение для составления ежемесячных отчётов Добровольной
Народной Дружины. Это наследник консольной утилиты `generate_report.py`: тот же
A4-дизайн (зелёная шапка, жёлтое название, эмблема, нумерованный список
мероприятий с подпунктами, подпись командира), но теперь с удобным GUI, живым
превью и генерацией PDF **прямо в браузере** — без сервера и без интернета.

## Возможности

- **Профили отрядов** — несколько ДНД в одном приложении. Переключение в шапке,
  создание/дублирование/удаление, у каждого отряда своя эмблема, данные, цвета,
  тексты, почта и история. Профиль можно экспортировать файлом и передать другому
  отряду (импорт одним кликом).
- **Два стиля бланка** (⚙ → Цвета → «Стиль бланка»):
  - *Модерн* (по умолчанию) — свежая вёрстка: лёгкая шапка, золотая линия, крупный
    заголовок месяца, строка-сводка (мероприятий / подпунктов / период), список как
    таймлайн с золотыми кружками-номерами и тонкими разделителями, аккуратный
    колонтитул с подписью и номером страницы. Шрифты PT Serif + PT Sans (встроены, офлайн).
  - *Классический* — точная копия исходного бланка matplotlib (зелёная плашка,
    DejaVu Sans). Остаётся доступен в один клик.
- **Окружение отряда** (панель ⚙ Настроить) — всё настраивается интерактивно:
  - *Отряд*: организация, муниципалитет, дружина, командир, строки шапки,
    эмблема (загрузка PNG/JPG) и фон под эмблемой.
  - *Цвета*: палитра бланка через color-picker (цвет шапки, название, заголовки,
    текст) с мгновенным превью.
  - *Тексты*: шаблоны «Отчёт за {month} {year}», подзаголовок и должность в
    подписи — раньше были зашиты в код, теперь редактируются.
  - *Почта*: адрес отправителя и **закрытый список адресатов** — при отправке
    получатель выбирается только из него.
- **Редактор мероприятий** — пункты и подпункты, перемещение ▲▼, авто-рост полей.
- **Живой превью** страницы A4 один-в-один с PDF, с пагинацией.
- **Скачивание PDF** офлайн — вёрстка и кириллица через встроенный DejaVu Sans
  (тот же шрифт, что использовал matplotlib).
- **Отправка отчёта** — кнопка ✉: на телефоне/Safari через системный «Поделиться»
  с вложенным PDF; на десктопе скачивает PDF и открывает почтовый клиент с готовым
  письмом выбранному адресату (PDF останется прикрепить вручную — браузер не
  вкладывает файлы в `mailto` из соображений безопасности).
- **История** отчётов по каждому отряду (IndexedDB) — открыть, переиздать, удалить.
  Архив старого проекта (август 2025 – май 2026) импортируется в отряд «Лукоморье»
  автоматически при первом запуске; повторно — кнопкой **⭳ Архив** в карточке истории.
- **Заполнение по образцу** — строки отчёта из месяца в месяц часто повторяются.
  Кнопка **📋 По образцу** заполняет все пункты из последнего сохранённого отчёта
  (нужно только отредактировать и подтвердить). Для пустых полей под ними
  показывается подсказка «образец: …» с кнопкой ✓ — подставить значение прошлого
  месяца точечно. Нет прошлых данных — обычный ввод, подсказки не мешают.
- **Импорт/экспорт месячного JSON** в формате старого проекта
  (`{ "month", "year", "activities" }`); постоянные поля в файле подхватятся в профиль.
- **PWA** — устанавливается как приложение, работает офлайн (service worker),
  тёмная/светлая тема интерфейса.

Данные первого запуска (отряд «Лукоморье», эмблема, реквизиты) переносятся из
старого проекта автоматически; старые сохранённые настройки мигрируют в профиль.

## Запуск

Service worker и загрузка шрифтов требуют http, поэтому не открывайте
`index.html` через `file://`. Поднимите локальный сервер:

```bash
cd dnd-report-pwa
python3 serve.py            # откроется http://localhost:8000
```

В Chrome справа в адресной строке появится значок «Установить». На телефоне —
«Добавить на экран Домой». После первого визита приложение работает офлайн.

## Отправка письма в один клик (сервер)

Браузер не умеет сам прикреплять файл к письму и не может слать SMTP напрямую,
поэтому для отправки «в один клик» есть крошечный сервер-релей на стандартной
библиотеке Python (без зависимостей). Он одновременно раздаёт само приложение и
принимает запрос на отправку, отправляя письмо с вложённым PDF по SMTP.

```bash
cd dnd-report-pwa
cp server/email_config.example.json server/email_config.json
# отредактируйте email_config.json: SMTP вашего ящика (для Яндекс/Mail/Gmail —
# ПАРОЛЬ ПРИЛОЖЕНИЯ, не основной пароль)
python3 server/send_server.py        # http://localhost:8000  (приложение + отправка)
```

Откройте приложение по этому адресу. В настройках **Почта** статус «Сервер
отправки: подключён» — теперь кнопка **✉ Отправить** отправляет письмо выбранному
адресату сразу, без ручного прикрепления. Поле «URL сервера отправки» оставьте
пустым (берётся текущий адрес); заполните его, только если сервер развёрнут на
другом домене.

Поведение кнопки ✉ каскадом:

1. **Сервер доступен** → отправка в один клик (PDF уходит вложением).
2. **Сервера нет, есть «Поделиться»** (телефон/Safari) → системный диалог с PDF.
3. **Иначе** → скачивание PDF + открытие почтового клиента с готовым письмом.

`email_config.json` содержит пароль и в `.gitignore` — в репозиторий не попадает.
Поле `allowed_recipients` (если не пустое) ограничивает, кому сервер вообще может
слать — дополнительная защита поверх закрытого списка в интерфейсе.

### Деплой

Боевая версия публикуется автоматически: при пуше в `main` GitHub Actions
(workflow `.github/workflows/deploy.yml`) выкладывает эту папку на GitHub Pages →
**https://dmitrtrc.github.io/dnd-reports/**

Это просто статика, поэтому её можно положить на любой хостинг с HTTPS (Netlify,
nginx и т.п.). Бэкенд не нужен. Главное — отдавать файлы по https, иначе
service worker не зарегистрируется. Все пути относительные, поэтому приложение
работает и из подпапки (как на Pages: `/dnd-reports/`).

## Структура

```
dnd-report-pwa/
├── index.html            # разметка GUI
├── css/styles.css        # тема и стили
├── js/
│   ├── app.js            # контроллер: форма, история, импорт/экспорт
│   ├── preview.js        # WYSIWYG-превью (та же геометрия, что PDF)
│   ├── report-pdf.js     # генерация PDF на pdf-lib (порт generate_report.py)
│   └── store.js          # обёртка над IndexedDB
├── vendor/               # pdf-lib + fontkit (офлайн, без CDN)
├── fonts/                # DejaVuSans[-Bold].ttf для кириллицы в PDF
├── icons/                # эмблема и иконки PWA
├── samples/              # примеры месячных JSON + константы
├── manifest.json
├── sw.js                 # service worker (офлайн-кэш)
└── serve.py              # локальный http-сервер
```

## Формат данных

Месячный отчёт (экспорт/импорт):

```json
{
  "month": "Май",
  "year": 2026,
  "activities": [
    { "text": "Ежедневные дежурства и патрулирование" },
    { "text": "Выявление нарушений", "subitems": ["Предотвращено 32 въезда", "8 нарушений"] }
  ]
}
```

Постоянные поля (`organization`, `station`, `team_name`, `commander`,
`small_lines`) хранятся в настройках приложения; если они есть в импортируемом
JSON — будут подхвачены.

## Тонкая настройка вёрстки

Геометрия и цвета берутся из `ReportPDF.DEFAULT_CONFIG` (см. `js/report-pdf.js`)
и совпадают с дефолтами Python-версии. Переопределения можно положить в
`settings.config` (объект как старый `config.json`: `logo_width_fraction`,
`logo_height_compensation`, `content_margin`, `colours` и т.д.).
